# ADR-001: Autorización síncrona y resto de tareas asíncronas

- **Tipo:** Arquitectónica
- **Estatus:** Aceptado

## Contexto
El cliente espera una respuesta rápida pero hay tareas lentas (notificar, conciliar).

## Decisión
Son síncronos solo validar cuenta, límites, registrar y consultar al banco; notificación y conciliación van en segundo plano.

## Justificación
Reduce la latencia percibida y aísla fallos de servicios secundarios.

## Consecuencias
Se necesita manejar el estado PENDIENTE_BANCO y la consistencia eventual.
